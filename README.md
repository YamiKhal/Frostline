# Frostline Worldgen v3 — Forge 1.20.1

Total overworld conversion. No vanilla biomes, no oceans, no rivers, no water,
no caves, no ores, **no trees of any kind**. 47 biomes across six regions.

Java does exactly two things — a coordinate-aware density function and a snow
accumulation feature. Both are things vanilla genuinely cannot express.
Everything else is datapack JSON generated by `gen3.py`.

---

## 1. Regions

Seven biomes per region, split by terrain tier so a region is varied without
losing its identity. Tiers come from the same `erosion` value that shapes the
terrain, so a "peak" biome cannot land on flat ground.

| Tier | erosion | count | split by |
|---|---|---|---|
| Peak | −1.00 … −0.55 | 2 | weirdness |
| Crag | −0.55 … −0.375 | 1 | — |
| Rolling | −0.375 … 0.20 | 2 | humidity |
| Flat | 0.20 … 1.00 | 2 | humidity |

**1 Hollow Drifts** — `hollow_spires` `windscoured_crags` `frost_shelf`
`drift_barrens` `rime_hollows` `frozen_hollow` *(spawn)* `snowveil_flats`

**2 Deadly Snowfields** — `frozen_spires` `glass_ridges` `shattered_shelf`
`deadly_snowfield` `crevasse_fields` `whiteout_flats` `bone_drifts`

**3 Ashen Wastes** — `cinder_ridges` `soot_spires` `slaghelm`
`ashen_snowfield` `ember_hollows` `ashfall_flats` `charred_barrens`

**4 Thawing Reach** — `slate_peaks` `tuff_spires` `grey_shelf` `slushfields`
`meltstone_hollows` `pale_flats` `gravel_barrens`

**5 Verdant Reach** — `emerald_bluffs` `verdant_crags` `mossy_shelf`
`verdant_downs` `sunlit_hollows` `verdant_plains` `sunlit_meadow`

**6 Ashlands** (southern easter egg) — `ashen_spires` `blackglass_ridge`
`tuffspine` `hollow_teeth` `soot_downs` `slag_hollows` `cracked_expanse`
`bone_shelf` `ashen_flats` `dust_barrens` `deepslate_pan` `the_quiet`

### What changed from v2

`grey_moors` is gone, and so is every other "grass that happens to be cold"
biome. The Thawing Reach is now grey rock, tuff, deepslate and thinning snow —
it reads as the snow running out, not as a meadow. Grass exists only in the
Verdant Reach.

Biome patches are also much smaller. `variety` went from xz_scale 0.55 to 1.15
and `erosion` from 0.22 to 0.30, and there are now 4 terrain tiers instead of 3.
Combined with 7 biomes per region instead of 3, you should be changing biome
every few hundred blocks rather than walking a kilometre of one thing.

## 2. Progression

`frostline:progression`, wired into the router's `temperature` slot.
`z_direction: -1.0` puts the payoff at compass north (−Z).

| v | z (compass north) | Region |
|---|---|---|
| −1.00 | 0 | 1 Hollow Drifts *(spawn)* |
| −0.55 | −11 250 | 2 Deadly Snowfields |
| −0.20 | −20 000 | 3 Ashen Wastes |
| +0.15 | −28 750 | 4 Thawing Reach |
| +0.60 | **−40 000** | 5 Verdant Reach |

Compass south runs the same order but `south_cap = 0.50` sits under the verdant
threshold, so from z ≈ +37 500 it is Thawing Reach — until the Ashlands.

### Ashlands

A second instance of the same density function, in the `continents` slot, with
`z_direction: +1.0` and `south_cap: -1.0` so it is pinned at −1 everywhere north
of spawn and ramps only southward. It crosses +0.60 — the Ashlands
continentalness threshold — at exactly **z = +80 000**.

Ashlands biomes claim continentalness 0.60…1.00; every other biome claims
−1.00…0.60. Since the Ashlands axis is flat at −1 across the whole north, the
region simply cannot appear there. Verified: z +79 000 is Thawing Reach,
z +80 000 is Ashlands, and it continues past z +300 000.

The Ashlands also **warp the terrain**, not just repaint it. An `ash_gate`
(0 before the threshold, 1 inside) feeds three things:

- `NEEDLE` — a `1 − |noise|` ridge term added to the height offset, producing
  spires and fins that exist nowhere else in the world
- `FACTOR` drops by 2.4 (floored at 0.55) — undercuts, overhangs, broken ground
- `JAGGEDNESS` gains a flat +0.14 everywhere, not just on ridge crests

The gate ramps in slightly *before* the biome boundary, so terrain starts going
wrong a few thousand blocks before the colours change.

No snow (`has_precipitation: false`), near-black fog, ash and soot particles,
and `the_quiet` gets basalt-deltas ambience and sculk patches.

## 3. Snow

This is what v2 got wrong, and the fix is not a tuning change.

**Java Edition's `freeze_top_layer` places exactly one snow layer, always.**
Bedrock Edition has a real snow-accumulation algorithm that Java never got: one
noise carves patches where no snow generates, a second noise creates patches
where multiple layers accumulate, and *a snow layer bordering a full block gains
one layer per bordering block*.

`frostline:snow_drift` is a port of that algorithm, plus a hollow-filling term.
Depth is tracked in **eighths**, so a value of 20 is two full snow blocks plus a
four-layer step — drifts can exceed one block and actually bury terrain steps
instead of tracing them.

1. low-frequency `bare` noise → wind-scoured patches with no snow
2. low-frequency `deep` noise → drifts up to `deep_strength` eighths
3. **+`border_bonus` per horizontally higher neighbour** — Bedrock's rule, and
   the one that does the smoothing. Snow banks against cliffs and staircases.
4. +`hollow_bonus` × (tallest neighbour − this column), capped at 3
5. above `powder_threshold` the full blocks become powder snow with a snow layer
   on top — invisible traps in the deepest drifts

Three presets: `snow_drift_deep` (Hollow Drifts, up to 26 eighths ≈ 3¼ blocks),
`snow_drift` (Deadly Snowfields, Ashen Wastes), `snow_drift_thin` (Thawing
Reach, max 8, no powder, aggressive bare patches so rock shows through).

The feature self-gates per column on `biome.getPrecipitationAt(pos) == SNOW`, so
it is safe to list anywhere; Ashlands and the Verdant Reach skip themselves.

Surface rules still place `snow_block` as ground material — the feature adds the
graded layers on top of that, not instead of it.

### Tuning it

All fields are codec-optional, so `"config": {}` uses the defaults.

| field | default | effect |
|---|---|---|
| `base_layers` | 2 | floor depth, in eighths |
| `max_layers` | 20 | ceiling (8 = one block) |
| `bare_scale` / `bare_threshold` | 0.022 / 0.58 | size and rarity of bare rock patches |
| `deep_scale` / `deep_strength` | 0.011 / 9.0 | size and depth of drifts |
| `border_bonus` | 1.6 | eighths per higher neighbour — **raise for smoother terrain** |
| `hollow_bonus` | 2.4 | eighths per block of hollow |
| `powder_threshold` | 0.80 | ≥1.0 disables powder traps |

## 4. Trees

None. All tree features and configured features are deleted, verified by an
automated check across all 47 biome files.

To add your own dead trees later: configured features in
`data/frostline/worldgen/configured_feature/`, placed features in
`placed_feature/`, then add the placed feature id to **both** the biome's step-9
list *and* to `MASTER[9]` in `gen3.py`, in the same relative position. Features
sharing a step across biomes must appear in a consistent global order or the
game throws a feature-order-cycle error at world load.

Note that vanilla's `minecraft:tree` feature requires dirt-family ground to
place, so snow-block surfaces will reject it. For leafless trees on snow you
want `minecraft:block_column` (see the `*_needle` features for the pattern) or a
custom feature that skips the ground check.

## 5. Terrain

```
offset  = -0.50375 + spline(erosion -> spline(ridges_folded)) + 0.055*relief + needle
factor  = max(0.55, spline(erosion) - 2.4*ash_gate)
jagged  = (spline(erosion, ridges) + 0.14*ash_gate) * half_negative(noise(jagged,1500))
depth   = y_gradient(-64..320, 1.5..-1.5) + offset
sloped  = 4 * quarter_negative((depth + jagged) * factor) + old_blended_noise
final   = squeeze(0.64 * interpolated(blend_density(slide(sloped))))
```

| Terrain | erosion | y |
|---|---|---|
| flats | +1.0 | ~71 |
| plains | +0.6 | ~73 |
| rolling | −0.15 | ~84 |
| tier boundary | −0.375 | ~110 |
| crag | −0.72 | ~156 |
| peak | −1.0 | ~174, jagged tips ~212 |

Water removed at the generator: `sea_level: -64`, `default_fluid: air`,
`aquifers_enabled: false`. Caves removed twice over: nothing cave-related in
`final_density`, and `"carvers": {}` on all 47 biomes. Ores: `ore_veins_enabled:
false` and no ore features.

Deepslate and netherrack appear as terrain, not decoration: `slate_peaks` has a
raised deepslate line (y96→y152), `cinder_ridges` a netherrack/blackstone core
(y72→y140), and the Ashlands three strata bands from bedrock upward.

## 6. Building

```
gradle wrapper --gradle-version 8.1.1     # once, if no wrapper present
./gradlew build
```

`build/libs/frostline-1.0.0.jar` → `mods/`. JDK 17. **Create a new world** —
the v2 world is on the old axis and the old biome set.

`optional/structures/` holds biome tags for igloos, snowy villages, plains
villages (green region only), outposts and ruined portals; copy its `data/` over
`src/main/resources/data/` before building to enable. Off by default.

## 7. Tuning cheatsheet

| Want | Change |
|---|---|
| Ashlands nearer/further | `north_range` on the `ASH_RAW` instance (100000 → threshold at 80k) |
| Verdant nearer/further | `north_range` on `PROGRESSION` |
| Payoff back at +Z | `z_direction: 1.0` |
| Smaller biome patches | raise `xz_scale` on `VARIETY` / `EROSION` |
| Wilder Ashlands terrain | the `-2.4` on `FACTOR`, `0.30` on `NEEDLE` |
| Deeper snow | `border_bonus` and `deep_strength` in the drift configs |
| More exposed rock | lower `bare_threshold` |
| Taller mountains | `ridge_spline(base, amp)`; +0.0078125 offset = +1 block |

`gen3.py` regenerates every JSON. Edit it, not the output.

## 8. Verification status

Checked automatically across all 47 biomes: every file parses; every biome the
dimension references exists; every per-step feature list is a valid subsequence
of the master ordering (feature-order-cycle guard); no tree references anywhere;
every `frostline:` placed feature referenced exists on disk; all 28
snow-bearing biomes carry a drift feature and none exceeds the 0.15 snow
threshold. Region and Ashlands boundaries verified numerically.

v2 confirmed in-game that the progression codec, density chain, surface rule
tree, dimension and feature references all load on a real client. New in v3 and
therefore unproven at runtime:

- **`frostline:snow_drift`** — the Feature registration and its per-chunk loop.
  If snow is missing entirely, check the log for a registration error before
  touching config. If it is too deep or too sparse, that is config.
- **Reading neighbour heights one block outside the chunk.** The FEATURES stage
  provides a 3×3 chunk region so this is legal, but if you see chunk-loading
  stalls, clamp the sampling loop to 0…15 and accept seams at chunk borders.
- **`minecraft:sculk_patch_deep_dark`** in `the_quiet` — a vanilla placed
  feature reference; drop it from that biome's step-9 list if it errors.
- **Ashlands terrain warping.** If the far south generates as floating debris,
  `FACTOR`'s floor of 0.55 is too low; raise it toward 1.0.
